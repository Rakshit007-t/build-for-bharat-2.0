TRANSPARENCY

Methodology & limitations

A clear separation between what data describes, what a model predicts, and what cannot be concluded.

DATA SOURCES

Four organizer datasets

  • Analytics Jobs and DataScience Jobs for descriptive posting patterns.
  • JDS Skill Traits for the supplied salary-hike high/low classification target.
  • SDS Personality Traits for the supplied organizational success label.

PRIVACY

Local-only processing

Raw data, analysis, model training, and inference remain on this machine. The API exposes aggregates, model metadata, figures, and predictions; it does not serve raw rows. No external AI API is used.

ANALYSIS TYPES

How to read this prototype

  • Descriptive: counts and summaries characterize the supplied postings.
  • Predictive: cross-validated models estimate only their source dataset’s supplied labels.
  • Association: observed trait or skill relationships do not establish cause and effect.
  • Implication: business ideas are hypotheses, not proven outcomes.

VALIDATION

Modeling choices

Majority-class baseline, logistic regression, and random forest are compared with stratified cross-validation. Macro precision, recall, F1, accuracy, and ROC-AUC where available are reported. Small samples can make estimates unstable; cross-validation is not external validation.

KNOWN LIMITATIONS

Interpret results with care
