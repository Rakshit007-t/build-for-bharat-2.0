  • JDS Skill Traits for the supplied salary-hike class.

PRIVACY & OFFLINE

Local-only processing

Raw data, analysis, model training, and inference remain on this machine. The API exposes aggregates, model metadata, figures, and predictions; it does not serve raw rows. No external AI API or remote runtime dependency is used.

ANALYSIS TYPES

How to read this prototype

  • Descriptive: counts and summaries characterize the supplied postings.
  • Predictive: cross-validated models estimate only their source dataset’s supplied labels.
  • Association: observed trait or skill relationships do not establish cause and effect.
  • Implication: business ideas are hypotheses, not proven outcomes.

VALIDATION

Modeling choices

Majority-class baseline, logistic regression, and random forest are compared with stratified cross-validation. Macro precision, recall, F1, accuracy, and ROC-AUC where available are reported. Small samples can make estimates unstable; cross-validation is not external validation.

PREPARATION & FEATURES

How inputs are handled

  • Source headers and text are normalized in derived tables; missingness and duplicates are audited.
  • Job skill text is tokenized and normalized for aggregate mention counts.
  • JDS/SDS model features are numeric; complete cases are used for each model’s feature set and target.
  • Prediction forms enforce ranges recorded in local model metadata.
  • Target codes stay encoded as supplied; no undocumented mapping is inferred.

INTERPRETATION

Evidence limits

Results describe these supplied datasets. No causal claims are made, small validation samples are not external validation, and the trait model is not suitable for screening or ranking people.
